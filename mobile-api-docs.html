RMB Dubai -- Mobile API (v1) (1.0.0)

Download OpenAPI specification:

Official API for the RMB Dubai customer mobile app, covering account registration and KYC, project and site management, concrete order placement and tracking, payments and wallet, and customer support.

All endpoints are served under /api/mobile/v1 and, with the exception of the authentication endpoints listed below, require a bearer token obtained from Sign In or Sign Up.

For a getting-started guide, the authentication flow, and a full breakdown of integration status per feature, see the accompanying mobile-api.md and mobile-api-reference.md guides.
