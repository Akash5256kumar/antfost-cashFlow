RMB Dubai -- Mobile API (v1) (1.1.0)

Download OpenAPI specification:

License: Proprietary — RMB Dubai internal use

Customer mobile app API for RMB Dubai: registration and KYC, projects and sites, concrete orders, payments and wallet, support.

Bearer token on everything except /auth/*.

Changes in 1.1.0 -- no path or verb changed, so existing clients keep working.

  • Auth responses carry kyc, accountState, access, nextStep. A business awaiting KYC now signs in and is stopped at payment, not at the door. Branch on access, not is_kyc_verified.
  • Orders gain a Draft status and paymentStatus. An order stays a draft until payment succeeds.
  • services.pump is now a type plus a metre range, replacing size: small|medium|big.
  • siteAccess.narrowAccess and roadPermit become objects with a required flag and an uploaded fileId. boomPumpRequired removed.
  • imageUrl populated across catalogue, projects, orders, payments.
  • email is nullable -- sign-up never collected one.
  • AUTH_FAILED split into INVALID_CREDENTIALS / NOT_AN_APP_ACCOUNT; ACCOUNT_NOT_READY removed; list endpoints return 200 with isEmpty instead of NO_*_FOUND 404s.

Full notes: API-DOCS.md
